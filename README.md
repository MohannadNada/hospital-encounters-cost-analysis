# Hospital Encounters & Cost Analysis

## Overview
I used MySQL to analyze hospital encounter data and Tableau to visualize the results. The project focuses on encounter trends, costs, payer coverage, procedures, and patient behavior.

## Tools
- MySQL
- Tableau

## Dashboard
![Hospital Encounters & Cost Analysis](Hospital%20Encounters%20%26%20Cost%20Analysis.jpg)

## Analysis
The analysis covers:
- Encounter volume and types
- Procedure frequency and costs
- Claim costs by payer
- Payer coverage
- Patient volume and 30-day readmissions

## SQL Skills Used
- JOINs
- Subqueries
- GROUP BY
- CASE
- Aggregate functions
- COUNT(DISTINCT)
- TIMESTAMPDIFF
- YEAR and QUARTER
